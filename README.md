# E-Commerce Microservices Backend

Backend-only Spring Boot microservices project.

Services:
- api-gateway : 8080
- user-service : 8081
- product-service : 8082
- inventory-service : 8083
- order-service : 8084
- payment-service : 8085
- notification-service : 8086

Infrastructure:
- MySQL
- Redis
- Kafka
- Docker Compose

Java 21 / Spring Boot 3.5.x
